CAR CAB BOOKING: COMPLETE UPDATED PROJECT (SEO + AEO + GEO + WhatsApp form fix)

HOW TO USE
1. Keep a backup of your old project folder.
2. Copy everything from this folder into your project (Replace files). Keep your own node_modules.
   (Fresh PC: run  npm install  first.)
3. npm run check      -> must end with: [prerender] wrote 17 static HTML pages
4. npm run dev        -> test in the browser
5. npm run preview    -> test the production build (localhost:4173)
6. Push to a separate branch first, test the Cloudflare preview URL, then merge to main.

AFTER DEPLOY
- Search Console: submit sitemap.xml again, "Request indexing" for the 12 new URLs
- Bing Webmaster Tools: submit sitemap.xml
